## 💻 요즘 배우고 있는 코드
최근에는 아래와 같은 간단한 **Python** 테스팅 코드를 작성하며 테스팅 자동화 기초를 탄탄히 다지는 중입니다. 짧은 `print("Hello, QA World!")` 인라인 코드부터 시작하여 다양한 코드를 접하고 있는 중입니다.

```python
def main():
    message = "만나서 반갑습니다! QA로서 품질을 높여봐요."
    print(message)

if __name__ == "__main__":
    main()
```
